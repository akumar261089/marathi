# ⏰ UNIT 5: TENSES (काळ)

# 📘 Lesson 12: Present Tense (वर्तमानकाळ)

Present tense tells us about an action happening **now** or regularly.

### Hindi vs Marathi

| Hindi         | Marathi  |
| ------------- | -------- |
| मैं खाता हूँ  | मी खातो  |
| मैं पढ़ता हूँ | मी वाचतो |
| वह खेलता है   | तो खेळतो |
| वह खेलती है   | ती खेळते |

---

## 🔁 Present Tense Verb Endings

### Masculine

| Pronoun | Marathi |
| ------- | ------- |
| मी      | खातो    |
| तू      | खातोस   |
| तो      | खातो    |
| आम्ही   | खातो    |
| तुम्ही  | खाता    |
| ते      | खातात   |

---

## Examples

- मी शाळेत जातो.
- ती पुस्तक वाचते.
- तो पाणी पितो.
- मुले खेळतात.

---

### Feminine

| Pronoun | Marathi |
| ------- | ------- |
| मी      | खाते    |
| तू      | खातेस   |
| ती      | खाते    |
| आम्ही   | खातो    |
| तुम्ही  | खाता    |
| त्या    | खातात   |

---

### ✏️ A. Fill in the Blanks (10)

1. मी \_\_\_ (खातो / खातात)
2. तो \_\_\_ (खेळतो / खेळतात)
3. ती \_\_\_ (वाचते / वाचतो)
4. आम्ही \_\_\_ (जातो / जातात)
5. तुम्ही \_\_\_ (खाता / खातोस)
6. ते \_\_\_ (खेळतात / खेळतो)
7. मी शाळेत \_\_\_ (जातो / गेलो)
8. तो पाणी \_\_\_ (पितो / पिला)
9. ती पुस्तक \_\_\_ (वाचते / वाचली)
10. मुले \_\_\_ (खेळतात / खेळतो)

---

### ✏️ B. Hindi → Marathi (10)

1. मैं खाता हूँ।
2. वह खेलता है।
3. वह पढ़ती है।
4. हम स्कूल जाते हैं।
5. आप खाना खाते हैं।
6. बच्चे खेलते हैं।
7. मैं पानी पीता हूँ।
8. वह गाना गाती है।
9. लड़के दौड़ते हैं।
10. हम घर में बैठते हैं।

---

### ✏️ C. Marathi → Hindi (10)

1. मी खातो.
2. तो खेळतो.
3. ती वाचते.
4. आम्ही शाळेत जातो.
5. तुम्ही खाता.
6. ते खेळतात.
7. मी पाणी पितो.
8. ती गाते.
9. मुले धावतात.
10. आम्ही घरात बसतो.

# 📘 Lesson 13: Past Tense (भूतकाळ)

Past tense tells us about something that **already happened**.

### Hindi vs Marathi

| Hindi   | Marathi       |
| ------- | ------------- |
| मैं गया | मी गेलो       |
| मैं गई  | मी गेले       |
| वह खाया | त्याने खाल्ले |
| वह पढ़ी | तिने वाचले    |

---

## 🔁 Common Past Forms

### Go (जाणे)

| Present | Past |
| ------- | ---- |
| जातो    | गेलो |
| जाते    | गेले |
| जातात   | गेले |

---

### Eat (खाणे)

| Present | Past   |
| ------- | ------ |
| खातो    | खाल्ले |
| खाते    | खाल्ले |
| खातात   | खाल्ले |

---

### Read (वाचणे)

| Present | Past  |
| ------- | ----- |
| वाचतो   | वाचले |
| वाचते   | वाचले |
| वाचतात  | वाचले |

---

## Examples

- मी काल शाळेत गेलो.
- ती घरी गेली.
- आम्ही क्रिकेट खेळलो.
- मुलांनी धाव घेतली.

---

### ✏️ A. Fill in the Blanks (10)

1. मी काल शाळेत \_\_\_.
2. ती घरी \_\_\_.
3. आम्ही क्रिकेट \_\_\_.
4. तो बाजारात \_\_\_.
5. मी पुस्तक \_\_\_.
6. ती गाणे \_\_\_.
7. मुले मैदानात \_\_\_.
8. आम्ही जेवण \_\_\_.
9. तो घरी \_\_\_.
10. ती शाळेत \_\_\_.

(गेली, गेलो, खेळलो, वाचले, गायली, धावली, खाल्ले)

---

1. मैं स्कूल गया।

4. उसने किताब पढ़ी।
5. लड़के दौड़े।
6. लड़की गाना गाई।
7. हमने खाना खाया।
8. वह बाजार गया।
9. बच्चे खेले।
10. मैं कल आया।

---

### ✏️ C. Marathi → Hindi (10)

1. मी शाळेत गेलो.
2. मी घरी गेले.

# 📘 Lesson 14: Future Tense (भविष्यकाळ)

Future tense tells us about something that **will happen later**.

### Hindi vs Marathi

| Hindi      | Marathi |
| ---------- | ------- |
| मैं जाऊँगा | मी जाईन |
| मैं जाऊँगी | मी जाईन |
| वह जाएगा   | तो जाईल |
| वह जाएगी   | ती जाईल |

---

## 🔁 Future Forms

### Go (जाणे)

| Pronoun | Future |
| ------- | ------ |
| मी      | जाईन   |
| तू      | जाशील  |
| तो      | जाईल   |
| ती      | जाईल   |
| आम्ही   | जाऊ    |
| तुम्ही  | जाल    |
| ते      | जातील  |

---

### Eat (खाणे)

| Pronoun | Future |
| ------- | ------ |
| मी      | खाईन   |
| तू      | खाशील  |
| तो      | खाईल   |
| ती      | खाईल   |
| आम्ही   | खाऊ    |
| तुम्ही  | खाल    |
| ते      | खातील  |

---

## Examples

- मी उद्या शाळेत जाईन.
