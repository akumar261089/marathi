# 📘 Lesson 15: Asking Questions (प्रश्न विचारणे)

---

## 📖 Core Concept

Questions are formed using question words.

### Important Question Words

| Hindi  | Marathi   | Meaning  |
| ------ | --------- | -------- |
| क्या   | काय       | What     |
| कौन    | कोण       | Who      |
| कहाँ   | कुठे      | Where    |
| कब     | कधी       | When     |
| क्यों  | का        | Why      |
| कैसे   | कसा / कशी | How      |
| कितना  | किती      | How much |
| कौन सा | कोणता     | Which    |

---

## Examples

| Marathi Question   | Marathi Answer      |
| ------------------ | ------------------- |
| तुझे नाव काय आहे?  | माझे नाव राहुल आहे. |
| तू कुठे राहतोस?    | मी पुण्यात राहतो.   |
| तू शाळेत जातोस का? | हो, मी जातो.        |
| हे काय आहे?        | हे पुस्तक आहे.      |

---

# 📘 Lesson 16: Yes/No Questions (होय / नाही)

---

## 📖 Core Concept

Marathi often uses **का?** at the end.

### Examples

| Statement       | Question           |
| --------------- | ------------------ |
| तू शाळेत जातोस. | तू शाळेत जातोस का? |
| तो खेळतो.       | तो खेळतो का?       |
| ती गाते.        | ती गाते का?        |

---

### Answer Patterns

| Question              | Answer              |
| --------------------- | ------------------- |
| तू शाळेत जातोस का?    | हो, मी जातो.        |
| तू क्रिकेट खेळतोस का? | नाही, मी खेळत नाही. |

---

4. तुम्ही वाचता.
5. मुले धावतात.
6. तू खातोस.
7. ती येते.
8. तो बसतो.
9. तुम्ही शिकता.
10. ते खेळतात.

---

### ✏️ B. Answer Using हो / नाही

1. तू शाळेत जातोस का?
2. तू पाणी पितोस का?
3. तुला क्रिकेट आवडते का?
4. तू टीव्ही बघतोस का?
5. तू अभ्यास करतोस का?

---

### ✏️ C. Hindi → Marathi

1. क्या तुम स्कूल जाते हो?
2. क्या वह खेलता है?
3. क्या वह गाती है?
4. क्या आप पढ़ते हैं?
5. क्या बच्चे दौड़ते हैं?
6. क्या तुम खाते हो?
7. क्या वह आती है?

# 📘 Lesson 17: Daily Conversations (दैनंदिन संभाषण)

---

## 📖 Greetings

| English      | Marathi      |
| ------------ | ------------ |
| Hello        | नमस्कार      |
| Good morning | शुभ प्रभात   |
| How are you? | तू कसा आहेस? |
| I am fine    | मी ठीक आहे   |
| Thank you    | धन्यवाद      |
| Welcome      | स्वागत आहे   |
| Goodbye      | पुन्हा भेटू  |

---

## Conversation 1: Introduction

### Marathi

A: नमस्कार. तुझे नाव काय आहे?

B: माझे नाव राहुल आहे.

A: तू कुठे राहतोस?

B: मी पुण्यात राहतो.

A: धन्यवाद.

B: स्वागत आहे.

---

### Hindi

A: नमस्ते। तुम्हारा नाम क्या है?

B: मेरा नाम राहुल है।

A: तुम कहाँ रहते हो?

B: मैं पुणे में रहता हूँ।

A: धन्यवाद।

B: स्वागत है।

---

## Conversation 2: School

### Marathi

A: तू कोणत्या शाळेत जातोस?

B: मी विद्या मंदिर शाळेत जातो.

A: तुला अभ्यास आवडतो का?

B: हो, मला आवडतो.

A: कोणता विषय आवडतो?

B: गणित.

---

## Conversation 3: Friends

### Marathi

A: तुझा मित्र कोण आहे?

B: रोहन माझा मित्र आहे.

A: तुम्ही खेळता का?

B: हो, आम्ही क्रिकेट खेळतो.
