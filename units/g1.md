## 📘 Lesson G1.1: Karta Karak (कर्ता कारक)

### Function

Doer of action.

### Present Tense (वर्तमानकाळ)

- मी खातो. — मैं खाता हूँ।
- राम खेळतो. — राम खेलता है।
- ती वाचते. — वह (लड़की) पढ़ती है।

### Past Tense (भूतकाळ)

- रामने आंबा खाल्ला. — राम ने आम खाया।
- तिने पुस्तक वाचले. — उसने किताब पढ़ी।
- अमितने दूध प्यायले. — अमित ने दूध पिया।

### Learn

#### When "ने" appears

In Marathi, **ने** usually appears with the doer (कर्ता) in many completed past-tense actions.

Examples:

- रामने आंबा खाल्ला. — राम ने आम खाया।
- तिने पुस्तक वाचले. — उसने किताब पढ़ी।
- अमितने दूध प्यायले. — अमित ने दूध पिया।

**Formula:**

कर्ता + ने + कर्म + क्रिया

Example:

राम + ने + आंबा + खाल्ला

---

#### When "ने" does NOT appear

In present tense, future tense, and many ongoing actions, **ने** is usually not used.

Examples:

- मी खातो. — मैं खाता हूँ।
- राम खेळतो. — राम खेलता है।
- ती वाचते. — वह पढ़ती है।
- आम्ही जातो. — हम जाते हैं।
- मुलगा धावतो. — लड़का दौड़ता है।

**Formula:**

कर्ता + कर्म + क्रिया

Example:

राम + खेळतो

(No "ने")

## 📘 Lesson G1.2: Karma Karak (कर्म कारक)

### Object of Action (कर्म कारक)

The **karma (कर्म)** is the person, animal, or thing that receives the action.

---

### Without "ला"

Usually used with **non-living things (निर्जीव वस्तू)**.

- मी भाजी खातो. — मैं सब्ज़ी खाता हूँ।
- मी पुस्तक वाचतो. — मैं किताब पढ़ता हूँ।
- तो चेंडू फेकतो. — वह गेंद फेंकता है।

More examples:

- ती आंबा खाते. — वह आम खाती है।
- आम्ही चित्र काढतो. — हम चित्र बनाते हैं।
- मुलगा पाणी पितो. — लड़का पानी पीता है।

---

### With "ला"

Usually used with **people and animals (सजीव वस्तू)**.

- मी मुलाला बोलावले. — मैंने लड़के को बुलाया।
- तिने कुत्र्याला दूध दिले. — उसने कुत्ते को दूध दिया।
- मी मित्राला भेटलो. — मैं दोस्त से मिला।
- रामने आईला हाक मारली. — राम ने माँ को पुकारा।
- अमितने शिक्षकांना प्रश्न विचारला. — अमित ने शिक्षक से प्रश्न पूछा।

---

### Learn

#### When "ला" is used

Use **ला** when the object is usually a:

- Person (माणूस)
- Animal (प्राणी)

Examples:

- मुलाला बोलावले. — लड़के को बुलाया।
- आईला भेटलो. — माँ से मिला।
- कुत्र्याला दूध दिले. — कुत्ते को दूध दिया।
- मित्राला फोन केला. — दोस्त को फोन किया।

---

#### When "ला" is NOT used

Usually do not use **ला** with ordinary non-living things.

Examples:

- पुस्तक वाचले. — किताब पढ़ी।
- आंबा खाल्ला. — आम खाया।
- चेंडू फेकला. — गेंद फेंकी।
- पाणी प्यायलो. — पानी पिया।

---

### Easy Rule for Kids

**माणूस किंवा प्राणी → "ला" लावा**
(Person or animal → use "ला")

**वस्तू → "ला" लावू नका**
(Thing/object → usually do not use "ला")

Examples:

- मुलगा → मुलाला ✅
- मित्र → मित्राला ✅
- कुत्रा → कुत्र्याला ✅
- पुस्तक → पुस्तक ❌
- चेंडू → चेंडू ❌
- आंबा → आंबा ❌

# 📘 Lesson G1.3: Karan Karak (करण कारक)

## Function

Shows the tool, instrument, means, or method used to perform an action.

## Common Markers

- ने
- द्वारे
- वापरून

## Examples

### Using ने

- मी पेनने लिहिले. — मैंने पेन से लिखा।
- रामने सुरीने फळ कापले. — राम ने चाकू से फल काटा।
- तिने हाताने दरवाजा उघडला. — उसने हाथ से दरवाज़ा खोला।

### Using वापरून

- मी संगणक वापरून काम केले. — मैंने कंप्यूटर का उपयोग करके काम किया।
- त्याने मोबाइल वापरून फोटो काढला. — उसने मोबाइल का उपयोग करके फोटो लिया।
- आम्ही इंटरनेट वापरून माहिती शोधली. — हमने इंटरनेट का उपयोग करके जानकारी खोजी।

## Learn

### When to use करण कारक

Use it when answering:

**कशाने? (By what? / With what?)**

Examples:

- पेनने लिहिले.
- सुरीने कापले.
- हाताने उचलले.

# 📘 Lesson G1.4: Sampradan Karak (सम्प्रदान कारक)

## Function

Shows the receiver, beneficiary, or purpose.

## Common Marker

- साठी

## Examples

- आईसाठी फुले आणली. — माँ के लिए फूल लाए।
- मुलासाठी दूध आणले. — बच्चे के लिए दूध लाया।
- मित्रासाठी भेटवस्तू घेतली. — दोस्त के लिए उपहार खरीदा।
- शिक्षकांसाठी कार्यक्रम ठेवला. — शिक्षकों के लिए कार्यक्रम रखा।
- पाहुण्यांसाठी जेवण बनवले. — मेहमानों के लिए भोजन बनाया।

## Learn

Ask:

**कोणासाठी? (For whom?)**

Answer will usually take **साठी**.

# 📘 Lesson G1.5: Apadan Karak (अपादान कारक)

## Function

Shows separation, source, origin, or distance.

## Common Marker

- पासून

## Examples

- मी घरापासून दूर राहतो. — मैं घर से दूर रहता हूँ।
- तो मित्रापासून वेगळा झाला. — वह दोस्त से अलग हो गया।
- पुण्यापासून मुंबई दूर आहे. — पुणे से मुंबई दूर है।
- शाळेपासून घरी आलो. — स्कूल से घर आया।
- सकाळपासून पाऊस पडत आहे. — सुबह से बारिश हो रही है।

## Learn

Ask:

**कोठून? (From where?)**

**कुणापासून? (From whom?)**

# 📘 Lesson G1.6: Sambandh Karak (संबंध कारक)

## Function

Shows ownership, possession, or relationship.

## Common Markers

- चा
- ची
- चे
- च्या

## Examples

- रामचा मित्र आला. — राम का दोस्त आया।
- सीतेची बॅग हरवली. — सीता का बैग खो गया।
- घराचे दार उघडे आहे. — घर का दरवाज़ा खुला है।
- मुलांच्या खेळण्यांचा आवाज येतो. — बच्चों के खिलौनों की आवाज़ आती है।
- शाळेच्या मैदानात खेळ चालू आहे. — स्कूल के मैदान में खेल चल रहा है।

## Learn

| Gender         | Marker |
| -------------- | ------ |
| Masculine      | चा     |
| Feminine       | ची     |
| Neuter         | चे     |
| Plural/Oblique | च्या   |

# 📘 Lesson G1.7: Adhikaran Karak (अधिकरण कारक)

## Function

Shows place or location.

## Common Markers

- मध्ये
- वर
- आत
- येथे
- त

## Examples

- घरात बसलो. — घर में बैठा।
- टेबलवर पुस्तक आहे. — मेज पर किताब है।
- शाळेत मुले खेळतात. — स्कूल में बच्चे खेलते हैं।
- बागेत फुले आहेत. — बगीचे में फूल हैं।
- खोलीमध्ये संगणक आहे. — कमरे में कंप्यूटर है।

# 📘 Lesson G1.8: Sambodhan Karak (संबोधन कारक)

## Function

Used while calling or addressing someone.

## Common Markers

- अरे
- अगं
- ए
- हो
- मुलांनो

## Examples

- अरे राम, इकडे ये! — अरे राम, इधर आओ!
- ऐक मित्रा! — सुनो दोस्त!
- मुलांनो, शांत बसा. — बच्चों, शांत बैठो।
- हो बाबा, मी येतो. — हाँ पिताजी, मैं आता हूँ।
- अगं सीते, ऐक ना! — अरे सीता, सुनो ना!

## Learn

Used when directly speaking to someone.
