## 📘 Lesson G6.3: Relative Structures

### जो ... तो

- जो अभ्यास करतो तो पास होतो.

### जिथे ... तिथे

- जिथे पाणी आहे तिथे झाडे आहेत.

### जेव्हा ... तेव्हा

- जेव्हा पाऊस पडतो तेव्हा आम्ही घरी राहतो.

# 🎯 Final Outcome

After completing:

- Units 1–20 (Speaking Track)
- Grammar Units G1–G8

The learner will understand:

✅ Marathi sentence structure
✅ All major Karaks
✅ Verb agreement rules
✅ Pronoun transformations
✅ Advanced tense system
✅ Relative clauses
✅ Natural spoken Marathi particles
✅ Formal and informal writing

This covers roughly **90–95% of practical Marathi grammar needed for B2-level fluency** for a Hindi speaker.
Adding exercises is essential. Without exercises, the Grammar Track becomes a reference book rather than a learning course.

The best structure is:

- Explanation
- Examples
- Pattern Table
- Exercise A (Recognition)
- Exercise B (Fill in the Blanks)
- Exercise C (Transformation)
- Exercise D (Hindi → Marathi)
- Exercise E (Marathi → Hindi)
- Exercise F (Writing)

Below is the expanded format for the first grammar unit. The same pattern should be used for all G1–G8 units.
