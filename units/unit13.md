After this unit, the learner will be able to:

✅ Tell time in Marathi

# 📘 Lesson 46: Telling Time

# (वेळ सांगणे)

---

## 📖 Core Concept

### Asking Time

**किती वाजले आहेत?**
= What time is it?

---

## Full Hours

| Time  | Marathi    |
| ----- | ---------- |
| 1:00  | एक वाजला   |
| 2:00  | दोन वाजले  |
| 3:00  | तीन वाजले  |
| 4:00  | चार वाजले  |
| 5:00  | पाच वाजले  |
| 6:00  | सहा वाजले  |
| 7:00  | सात वाजले  |
| 8:00  | आठ वाजले   |
| 9:00  | नऊ वाजले   |
| 10:00 | दहा वाजले  |
| 11:00 | अकरा वाजले |
| 12:00 | बारा वाजले |

---

## Half Hours

| ----- | ------- |

---

## Quarter Hours

| Time | Marathi  |
| ---- | -------- |

| 2:45 | पावणेतीन |
| 5:15 | सव्वापाच |

---

## Examples

- आता पाच वाजले आहेत.
- मी साडेसहा वाजता उठतो.
- शाळा आठ वाजता सुरू होते.
- आम्ही पावणेनऊ वाजता पोहोचलो.

# 📘 Lesson 47: Days of the Week

# (आठवड्याचे दिवस)

---

## 📖 Days

| English   | Marathi  |
| --------- | -------- |
| Monday    | सोमवार   |
| Tuesday   | मंगळवार  |
| Wednesday | बुधवार   |
| Thursday  | गुरुवार  |
| Friday    | शुक्रवार |
| Saturday  | शनिवार   |
| Sunday    | रविवार   |

---

## Examples

- आज सोमवार आहे.
- उद्या मंगळवार आहे.
- काल रविवार होता.
- माझी परीक्षा गुरुवारी आहे.

---

## Time Words

| Marathi | Meaning                                   |
| ------- | ----------------------------------------- |
| आज      | today                                     |
| काल     | yesterday                                 |
| उद्या   | tomorrow                                  |
| परवा    | day before yesterday / day after tomorrow |
| रोज     | every day                                 |

---

## ✏️ PRACTICE — LESSON 47

### ✏️ A. Translate

1. Monday
2. Thursday
3. Sunday
4. Friday
5. Tuesday

---

### ✏️ B. Hindi → Marathi

1. आज सोमवार है।
2. कल रविवार था।
3. मेरी परीक्षा शुक्रवार को है।
4. हम रोज स्कूल जाते हैं।
5. कल मंगलवार होगा।

---

### ✏️ C. Writing Practice

Write one sentence for each day of the week.

# 📘 Lesson 48: Months, Dates & Seasons

# (महिने, दिनांक आणि ऋतू)

---

## 📖 Months

| English   | Marathi    |
| --------- | ---------- |
| January   | जानेवारी   |
| February  | फेब्रुवारी |
| March     | मार्च      |
| April     | एप्रिल     |
| May       | मे         |
| June      | जून        |
| July      | जुलै       |
| August    | ऑगस्ट      |
| September | सप्टेंबर   |
| October   | ऑक्टोबर    |
| November  | नोव्हेंबर  |
| December  | डिसेंबर    |

---

## Dates

Examples:

- आज १५ जून आहे.
- माझा वाढदिवस १० ऑगस्टला आहे.
- परीक्षा २ मार्चला आहे.

---

## Seasons

| Marathi | Meaning |
| ------- | ------- |
| उन्हाळा | Summer  |
| पावसाळा | Monsoon |
| हिवाळा  | Winter  |

## Examples

- हिवाळ्यात थंडी असते.
- उन्हाळ्यात गरमी असते.

# 📘 Lesson 49: Daily Routine & Scheduling

# (दैनंदिन दिनक्रम)

---

## 📖 Common Time Expressions

| Marathi    | Meaning          |
| ---------- | ---------------- |
| सकाळी      | in the morning   |
| दुपारी     | in the afternoon |
| संध्याकाळी | in the evening   |
| रात्री     | at night         |

---

## Example Routine

- मी सकाळी सहा वाजता उठतो.
- मी सात वाजता नाश्ता करतो.
- मी आठ वाजता काम सुरू करतो.
- मी दुपारी जेवतो.
- मी रात्री दहा वाजता झोपतो.

---

## Useful Verbs

- उठणे
- आंघोळ करणे
- नाश्ता करणे
- अभ्यास करणे
- काम करणे
- जेवणे
- झोपणे

---

# 📘 Lesson 50: Appointments, Meetings & Plans

# (भेटी, बैठक आणि नियोजन)

---

## 📖 Making Plans

### Examples

- आपण उद्या भेटूया.
- बैठक दुपारी तीन वाजता आहे.
- माझी डॉक्टरांची अपॉइंटमेंट आहे.
- आपण शनिवारी जाऊया.
- कार्यक्रम रविवारी आहे.

---

## Asking About Plans

- तू उद्या मोकळा आहेस का?
- आपण किती वाजता भेटू?
- बैठक कधी आहे?
- कार्यक्रम कुठे आहे?

---

## Responses

- मी मोकळा आहे.
- मी व्यस्त आहे.
- मी येऊ शकतो.
- मला उशीर होईल.

---

## ✏️ PRACTICE — LESSON 50

### ✏️ A. Complete the Dialogue

A: आपण **\_** भेटूया?

B: आपण **\_** वाजता भेटूया.

A: ठीक आहे.

---

### ✏️ B. Hindi → Marathi

1. हम कल मिलेंगे।
2. बैठक तीन बजे है।
3. कार्यक्रम रविवार को है।
4. क्या तुम कल खाली हो?
5. हम कितने बजे मिलें?
