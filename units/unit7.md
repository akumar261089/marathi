# 📘 Lesson 18: Adjectives (विशेषण)

## 📖 Core Concept

An **adjective (विशेषण)** describes a noun.

### Examples

| Noun   | Adjective   | Meaning        |
| ------ | ----------- | -------------- |
| मुलगा  | मोठा मुलगा  | big boy        |
| मुलगी  | सुंदर मुलगी | beautiful girl |
| घर     | मोठे घर     | big house      |
| पुस्तक | नवीन पुस्तक | new book       |

---

## 🔁 Variable Adjectives

These change according to gender.

### Example: मोठा

| Gender    | Marathi       |
| --------- | ------------- |
| Masculine | मोठा          |
| Feminine  | मोठी          |
| Neuter    | मोठे          |
| Plural    | मोठे / मोठ्या |

---

### Examples

- मोठा मुलगा
- मोठी मुलगी
- मोठे घर
- मोठी झाडे

---

## 🔁 Invariant Adjectives

These do NOT change.

### Examples

| Adjective | Meaning         |
| --------- | --------------- |
| लहान      | small           |
| सुंदर     | beautiful       |
| हुशार     | intelligent     |
| चांगला\*  | good (variable) |

Examples:

- लहान मुलगा
- लहान मुलगी
- सुंदर घर
- हुशार विद्यार्थी

# 📘 Lesson 20: Adverbs & Feelings

## (क्रियाविशेषण आणि भावना)

---

## 📖 Core Concept

An **adverb (क्रियाविशेषण)** describes a verb.

### Examples

| Marathi | Meaning |
| ------- | ------- |
| हळू     | slowly  |
| पटकन    | quickly |
| चांगले  | well    |
| शांतपणे | quietly |
| जोरात   | loudly  |

---

### Examples

- तो हळू चालतो.
- ती पटकन धावते.
- तो चांगले गातो.
- मुलं जोरात बोलतात.

---

## Feelings & Emotions

| Marathi   | Meaning |
| --------- | ------- |
| आनंदी     | happy   |
| दुःखी     | sad     |
| रागावलेला | angry   |
| घाबरलेला  | scared  |
| उत्साही   | excited |
| थकलेला    | tired   |

---

## Examples

- मी आनंदी आहे.
- तो दुःखी आहे.
- ती उत्साही आहे.
- आम्ही आनंदी आहोत.

---
