# 🎯 UNIT 5 FINAL REVIEW

## A. Identify the Tense

| Sentence  | Tense      |
| --------- | ---------- |
| मी खातो   | वर्तमानकाळ |
| मी खाल्ले | भूतकाळ     |
| मी खाईन   | भविष्यकाळ  |
| तो खेळतो  | वर्तमानकाळ |
| तो खेळला  | भूतकाळ     |
| तो खेळेल  | भविष्यकाळ  |
| ती वाचते  | वर्तमानकाळ |
| ती वाचली  | भूतकाळ     |
| ती वाचेल  | भविष्यकाळ  |
| आम्ही जाऊ | भविष्यकाळ  |

---

## B. Hindi → Marathi

1. मैं खाना खाता हूँ।
   → मी जेवण खातो.

2. मैंने खाना खाया।
   → मी जेवण खाल्ले.

3. मैं खाना खाऊँगा।
   → मी जेवण खाईन.

4. वह स्कूल जाता है।
   → तो शाळेत जातो.

5. वह स्कूल गया।
   → तो शाळेत गेला.

6. वह स्कूल जाएगा।
   → तो शाळेत जाईल.

7. लड़की गाना गाती है।
   → मुलगी गाणे गाते.

8. लड़की गाना गाई।
   → मुलगी गाणे गायली.

9. लड़की गाना गाएगी।
   → मुलगी गाणे गाईल.

10. हम घर जाएंगे।
    → आम्ही घरी जाऊ.

---
