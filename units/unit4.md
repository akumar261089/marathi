# 📚 UNIT 4: CASES & POSTPOSITIONS (विभक्ती आणि शब्दयोगी अव्यय)

## 🎯 Goal (उद्दिष्ट)

Learn how Marathi changes nouns and pronouns when showing:

| Marathi          | Hindi            | Meaning                    |
| ---------------- | ---------------- | -------------------------- |
| **ला**           | **को**           | To whom? / किसको?          |
| **मध्ये / -त**   | **में**          | In whom/where? / कहाँ में? |
| **पासून**        | **से**           | From whom? / किससे?        |
| **सोबत**         | **के साथ**       | With whom? / किसके साथ?    |
| **चा / ची / चे** | **का / की / के** | Of whom? / किसका?          |

These are called **Cases (विभक्ती)**.

**हिंदी में** इन्हें **कारक चिह्न** या **परसर्ग (Postpositions)** कहा जाता है।
जैसे हिंदी में _को, से, में, का, की, के, साथ_ लगते हैं, वैसे ही मराठी में _ला, पासून, मध्ये, चा, ची, चे, सोबत_ लगते हैं।

---

## 📘 What is a Case? (विभक्ती म्हणजे काय?)

A **Case (विभक्ती)** shows the relationship between a noun/pronoun and the rest of the sentence.

**Hindi Explanation:**

जब किसी संज्ञा (Noun) या सर्वनाम (Pronoun) का वाक्य में किसी अन्य शब्द से संबंध दिखाना हो, तब विभक्ति (Case Marker) लगाई जाती है।

### Examples

| Marathi            | Hindi                  |
| ------------------ | ---------------------- |
| रामला पुस्तक दिले. | राम **को** किताब दी।   |
| शाळेत गेलो.        | स्कूल **में** गया।     |
| मित्रासोबत खेळलो.  | मित्र **के साथ** खेला। |
| आईचे घर.           | माँ **का** घर।         |

---

## 📘 Common Marathi Cases

### 1️⃣ ला (Dative Case)

**Meaning:** To / For someone

**Hindi Equivalent:** **को**

Examples:

| Marathi               | Hindi                              |
| --------------------- | ---------------------------------- |
| मुलाला बोलावले.       | लड़के **को** बुलाया।               |
| आईला भेटलो.           | माँ **से** मिला / माँ **को** मिला। |
| मित्राला पत्र लिहिले. | मित्र **को** पत्र लिखा।            |
| कुत्र्याला दूध दिले.  | कुत्ते **को** दूध दिया।            |

---

### 2️⃣ मध्ये / -त (Locative Case)

**Meaning:** In / Inside / At

**Hindi Equivalent:** **में**

Examples:

| Marathi                | Hindi                     |
| ---------------------- | ------------------------- |
| घरात आहे.              | घर **में** है।            |
| शाळेत जातो.            | स्कूल **में** जाता हूँ।   |
| पिशवीमध्ये पुस्तक आहे. | बैग **में** किताब है।     |
| पाण्यात मासे आहेत.     | पानी **में** मछलियाँ हैं। |

---

### 3️⃣ पासून (Ablative Case)

**Meaning:** From

**Hindi Equivalent:** **से**

Examples:

| Marathi                    | Hindi                        |
| -------------------------- | ---------------------------- |
| पुण्यापासून मुंबई दूर आहे. | पुणे **से** मुंबई दूर है।    |
| मित्रापासून मदत मिळाली.    | मित्र **से** मदद मिली।       |
| आजपासून अभ्यास सुरू.       | आज **से** पढ़ाई शुरू।        |
| सकाळपासून पाऊस पडतोय.      | सुबह **से** बारिश हो रही है। |

---

### 4️⃣ सोबत (Comitative Case)

**Meaning:** With

**Hindi Equivalent:** **के साथ**

Examples:

| Marathi                  | Hindi                       |
| ------------------------ | --------------------------- |
| मी मित्रासोबत गेलो.      | मैं मित्र **के साथ** गया।   |
| आईसोबत बाजारात गेलो.     | माँ **के साथ** बाज़ार गया।  |
| भावासोबत खेळलो.          | भाई **के साथ** खेला।        |
| शिक्षकांसोबत चर्चा केली. | शिक्षक **के साथ** चर्चा की। |

---

### 5️⃣ चा / ची / चे (Genitive Case)

**Meaning:** Of / Belonging to

**Hindi Equivalent:** **का / की / के**

| Marathi       | Hindi              |
| ------------- | ------------------ |
| रामचा मित्र   | राम **का** मित्र   |
| सीतेची बहीण   | सीता **की** बहन    |
| मुलाचे पुस्तक | बच्चे **की** किताब |
| घराचे दार     | घर **का** दरवाज़ा  |

### Gender Agreement

| Marathi     | Hindi        |
| ----------- | ------------ |
| रामचा मित्र | राम का मित्र |
| रामची बहीण  | राम की बहन   |
| रामचे घर    | राम का घर    |

**Rule:**

- **चा** → Masculine noun (पुल्लिंग)
- **ची** → Feminine noun (स्त्रीलिंग)
- **चे** → Neuter/Plural noun (नपुंसकलिंग/बहुवचन)

---

## 📝 Quick Comparison: Hindi → Marathi

| Hindi                 | Marathi                           |
| --------------------- | --------------------------------- |
| लड़के **को** बुलाओ।   | मुलाला बोलवा.                     |
| घर **में** जाओ।       | घरात जा.                          |
| दोस्त **से** बात करो। | मित्राशी बोला / मित्रापासून नाही. |
| दोस्त **के साथ** जाओ। | मित्रासोबत जा.                    |
| राम **का** घर         | रामचे घर                          |

3. मैं दोस्त के साथ गया।
4. माँ से बात की।
5. यह राम की किताब है।

### Answers

1. मुलाला पाणी द्या.
2. मी शाळेत आहे.
3. मी मित्रासोबत गेलो.

5. हे रामचे पुस्तक आहे.

---

## 🔑 Summary

| Marathi Case | Hindi Equivalent | Usage      |
| ------------ | ---------------- | ---------- |
| ला           | को               | To someone |
| मध्ये / -त   | में              | In/Inside  |
| पासून        | से               | From       |
| सोबत         | के साथ           | With       |
| चा / ची / चे | का / की / के     | Possession |

**Memory Trick:**

> हिंदी में **को, में, से, के साथ, का/की/के**
> मराठी में **ला, मध्ये/त, पासून, सोबत, चा/ची/चे**.

# 📘 Lesson 9: The "ला" Case (Dative Case)

## (To / For Someone)

---

## 📖 Core Concept

We use **ला** when something is given, told, shown, or done **to someone**.

### Hindi → Marathi

| Hindi | Marathi       |
| ----- | ------------- |
| मुझे  | मला           |
| तुझे  | तुला          |
| उसे   | त्याला / तिला |
| हमें  | आम्हाला       |

---

### Examples

| Hindi                 | Marathi               |
| --------------------- | --------------------- |
| माँ मुझे बुलाती है    | आई मला बोलावते        |
| शिक्षक उसे पढ़ाते हैं | शिक्षक त्याला शिकवतात |
| मैं राम को देखता हूँ  | मी रामला पाहतो        |

---

## 🔁 Pronoun Changes

| Base Pronoun | With "ला" |
| ------------ | --------- |
| मी           | मला       |
| आम्ही        | आम्हाला   |
| तू           | तुला      |
| तुम्ही       | तुम्हाला  |
| तो           | त्याला    |
| ती           | तिला      |
| ते (plural)  | त्यांना   |

---

# 📘 Lesson 10: Location Words (मध्ये / -त)

## (In / At / Inside)

---

## 📖 Core Concept

Location tells **where something happens**.

### Common Location Words

| Hindi     | Marathi |
| --------- | ------- |
| घर में    | घरात    |
| स्कूल में | शाळेत   |
| कमरे में  | खोलीत   |
| पानी में  | पाण्यात |
| शहर में   | शहरात   |

---

### Examples

| Hindi                     | Marathi             |
| ------------------------- | ------------------- |
| मैं घर में हूँ            | मी घरात आहे         |
| वह स्कूल में है           | तो शाळेत आहे        |
| बच्चे मैदान में खेलते हैं | मुले मैदानात खेळतात |

---

## 🔁 Important Rule

Location words usually **do not change by gender**.

| Masculine    | Feminine      | Neuter       |
| ------------ | ------------- | ------------ |
| राम घरात आहे | सीता घरात आहे | घर शहरात आहे |

---

## ✏️ PRACTICE — LESSON 10

5. तो \_\_\_ आहे. (घरात / खातो)

# 📘 Lesson 11: Possession (चा / ची / चे)

## (Of / Belonging To)

---

## 📖 Core Concept

Used to show **ownership or relation**.

### Examples

| Hindi         | Marathi       |
| ------------- | ------------- |
| राम का घर     | रामचे घर      |
| सीता की किताब | सीतेचे पुस्तक |
| मेरा मित्र    | माझा मित्र    |
| मेरी बहन      | माझी बहीण     |

---

## 🔁 Gender Controls the Ending

### Masculine Noun

| Marathi     |
| ----------- |
| माझा मित्र  |
| तुझा भाऊ    |
| रामचा मुलगा |

---

### Feminine Noun

| Marathi     |
| ----------- |
| माझी बहीण   |
| तुझी आई     |
| रामची मुलगी |

---

### Neuter Noun

| Marathi     |
| ----------- |
| माझे घर     |
| तुझे पुस्तक |
| रामचे झाड   |

---
