# 📚 UNIT 12: COMPARISONS

# (तुलना)

## 🎯 Goal

After this unit, the learner will be able to:

✅ Compare people, objects, places, and actions
✅ Use **पेक्षा** (than) correctly
✅ Use **सर्वात** (the most) correctly
✅ Compare size, age, speed, intelligence, price, etc.
✅ Express equality and inequality naturally

---

# 📘 Lesson 41: Comparative Degree

# (पेक्षा)

---

## 📖 Core Concept

In Marathi:

### Than = पेक्षा

---

## Formula

**A + B पेक्षा + adjective**

---

## Examples

| Hindi                         | Marathi                                 |
| ----------------------------- | --------------------------------------- |
| राम मोहन से लंबा है           | राम मोहनपेक्षा उंच आहे                  |
| यह किताब उस किताब से अच्छी है | हे पुस्तक त्या पुस्तकापेक्षा चांगले आहे |
| पुणे मुंबई से शांत है         | पुणे मुंबईपेक्षा शांत आहे               |

---

## More Examples

- अमित राहुलपेक्षा वेगवान आहे.
- ही कार त्या कारपेक्षा महाग आहे.
- माझे घर तुझ्या घरापेक्षा मोठे आहे.
- आज कालपेक्षा थंड आहे.

---

## Common Adjectives

| Marathi | Meaning        |
| ------- | -------------- |
| मोठा    | bigger         |
| लहान    | smaller        |
| उंच     | taller         |
| वेगवान  | faster         |
| सुंदर   | more beautiful |
| चांगला  | better         |
| महाग    | more expensive |
| स्वस्त  | cheaper        |
| हुशार   | smarter        |
| मजबूत   | stronger       |

# 📘 Lesson 42: Superlative Degree

# (सर्वात)

---

## 📖 Core Concept

Used for:

### Most / Biggest / Best

---

## Formula

**सर्वात + adjective**

---

## Examples

| Hindi      | Marathi       |
| ---------- | ------------- |
| सबसे बड़ा  | सर्वात मोठा   |
| सबसे सुंदर | सर्वात सुंदर  |
| सबसे तेज   | सर्वात वेगवान |
| सबसे अच्छा | सर्वात चांगला |

---

## Examples

- राम वर्गात सर्वात हुशार आहे.
- हे शहर सर्वात मोठे आहे.
- ती आमच्या शाळेत सर्वात चांगली विद्यार्थिनी आहे.
- हा खेळाडू सर्वात वेगवान आहे.

---

## ✏️ PRACTICE — LESSON 42

3. ती **\_** सुंदर आहे.
4. हा खेळाडू **\_** वेगवान आहे.
5. हे पुस्तक **\_** चांगले आहे.
6. तो **\_** उंच आहे.

8. हे झाड **\_** मोठे आहे.
9. ती **\_** मेहनती आहे.

# 📘 Lesson 43: Equality Comparison

# (एवढा / तितका)

---

## 📖 Core Concept

Used when two things are equal.

### As ... as

---

## Examples

| Hindi                 | Marathi               |
| --------------------- | --------------------- |
| वह मेरे जितना लंबा है | तो माझ्याइतका उंच आहे |
| यह उतना महंगा नहीं है | हे तितके महाग नाही    |
| वह उतनी तेज नहीं है   | ती तितकी वेगवान नाही  |

---

## Common Patterns

- इतका ... तितका
- एवढा ... तेवढा

---

## Examples

- तो माझ्याइतका उंच आहे.
- ही बॅग त्या बॅगेइतकी जड आहे.
- हे घर त्या घराइतके मोठे आहे.
- ती माझ्याइतकी हुशार आहे.

---

## ✏️ PRACTICE — LESSON 43

### ✏️ A. Fill in the Blanks

1. तो माझ्या**\_** उंच आहे.
2. ती माझ्या**\_** हुशार आहे.
3. हे घर त्या घर**\_** मोठे आहे.
4. ही बॅग त्या बॅग**\_** जड आहे.
5. तो माझ्या भावा**\_** वेगवान आहे.
6. हे पुस्तक त्या पुस्तक**\_** चांगले आहे.
7. ती माझ्या बहिणी**\_** सुंदर आहे.
8. हा रस्ता त्या रस्त्या**\_** रुंद आहे.
9. तो माझ्या मित्रा**\_** मेहनती आहे.
10. ही कार त्या कार**\_** महाग आहे.

(इतका / इतकी / इतके)

---

### ✏️ B. Hindi → Marathi

1. वह मेरे जितना लंबा है।
2. वह मेरी बहन जितनी सुंदर है।
3. यह घर उस घर जितना बड़ा है।
4. यह बैग उस बैग जितना भारी है।
5. वह मेरे भाई जितना तेज है।
6. यह किताब उस किताब जितनी अच्छी है।
7. वह मेरी मित्र जितनी बुद्धिमान है।
8. यह सड़क उस सड़क जितनी चौड़ी है।
9. वह मेरे मित्र जितना मेहनती है।
10. यह कार उस कार जितनी महंगी है।

# 📘 Lesson 44: Comparing Actions

# (क्रियांची तुलना)

---

## 📖 Core Concept

We can compare actions too.

---

## Examples

- राम मोहनपेक्षा जास्त धावतो.
- ती माझ्यापेक्षा जास्त अभ्यास करते.
- अमित सर्वांपेक्षा जास्त काम करतो.
- मी तुझ्यापेक्षा कमी बोलतो.

---

## Useful Words

| Marathi  | Meaning |
| -------- | ------- |
| जास्त    | more    |
| कमी      | less    |
| अधिक     | more    |
| सर्वाधिक | most    |

---

## ✏️ PRACTICE — LESSON 44

### ✏️ A. Fill in the Blanks

1. राम मोहनपेक्षा **\_** धावतो.
2. ती माझ्यापेक्षा **\_** अभ्यास करते.
3. अमित सर्वांपेक्षा **\_** काम करतो.
4. मी तुझ्यापेक्षा **\_** बोलतो.
5. तो माझ्यापेक्षा **\_** खातो.
6. ती सर्वांपेक्षा **\_** शिकते.
7. आम्ही त्यांच्यापेक्षा **\_** खेळतो.
8. तो माझ्यापेक्षा **\_** वाचतो.
9. ती सर्वांपेक्षा **\_** गाते.
10. मी त्याच्यापेक्षा **\_** लिहितो.

(जास्त / कमी)

---

### ✏️ B. Hindi → Marathi

1. राम मोहन से ज्यादा दौड़ता है।
2. वह मुझसे ज्यादा पढ़ती है।
3. अमित सबसे ज्यादा काम करता है।
4. मैं तुमसे कम बोलता हूँ।
5. वह मुझसे ज्यादा खाता है।
6. वह सबसे ज्यादा सीखती है।
7. हम उनसे ज्यादा खेलते हैं।
8. वह मुझसे ज्यादा पढ़ता है।
9. वह सबसे ज्यादा गाती है।
10. मैं उससे कम लिखता हूँ।

---

### ✏️ C. Writing Practice

Write 10 sentences comparing actions.

# 🏆 UNIT 12 SUMMARY

- पेक्षा = than

- सर्वात = the most

- इतका / इतकी / इतके = as ... as

- जास्त = more
- कमी = less
